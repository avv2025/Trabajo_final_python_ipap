## 👩‍💻 Sobre el proyecto

¡Bienvenido/a a mi repositorio!

Este espacio reúne el desarrollo del Trabajo Parcial / Final del curso de **Desarrollo y Programación en Python – IPAP**.

El objetivo es integrar los conocimientos adquiridos durante la cursada mediante la resolución de diferentes ejercicios prácticos, aplicando conceptos fundamentales de programación, organización del código, modularidad y buenas prácticas de desarrollo.

Cada ejercicio representa una oportunidad para poner en práctica lo aprendido, fortalecer la lógica de programación y seguir desarrollando habilidades como estudiante.

## 🎯 Objetivos de aprendizaje

- Aplicar los fundamentos del lenguaje Python.
- Desarrollar soluciones utilizando funciones y estructuras de control.
- Incorporar conceptos de Programación Orientada a Objetos (POO).
- Trabajar con colecciones y manipulación de datos.
- Organizar proyectos mediante una estructura modular.
- Utilizar Git y GitHub para gestionar versiones y documentar el desarrollo.

## 📚 Contenidos aplicados

## ▶️ Cómo ejecutar los ejercicios

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Ingresar a la carpeta del proyecto:

```bash
cd Trabajo_final_python_ipap
```

3. Acceder al ejercicio que se desea ejecutar:

```bash
cd Ejercicio_1
```

4. Ejecutar el archivo Python:

```bash
python sensor_analisis.py
```
